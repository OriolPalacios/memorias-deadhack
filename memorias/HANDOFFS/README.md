# Traspasos entre agentes

La entrega primaria se registra en el **Issue y el PR**. Un archivo en esta carpeta solo es necesario cuando el trabajo es largo, hay decisiones técnicas importantes o debe cambiar de agente.

Nombre recomendado: `issue-N-YYYYMMDD-agente.md` para evitar que varios agentes editen el mismo archivo.

Usar [PLANTILLA.md](PLANTILLA.md). No pegar transcripciones completas de chats, secretos, tokens ni datos personales. Escribir hechos reproducibles: commit, comandos, resultados, restricciones, referencias y siguiente paso.

Si no se creó archivo, incluir las mismas secciones en el PR. El nuevo agente debe leer el PR y el Issue antes de continuar.
