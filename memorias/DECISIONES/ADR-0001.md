# ADR-0001 — Coordinación asíncrona mediante GitHub

**Estado:** propuesto para revisión del equipo.
**Fecha:** 2026-11-14.

## Contexto
El equipo dispone de tres suscripciones de IA operadas por personas distintas, sin memoria ni ejecución compartida automática. Se busca coordinación reproducible sin contratar APIs adicionales.

## Decisión propuesta
- Un único repositorio público, con `memorias/` para conocimiento compartido y aplicación fuera.
- GitHub Issues como cola y estado de trabajo.
- Ramas y Pull Requests como mecanismo de entrega y revisión.
- `AGENTS.md` y `CLAUDE.md` en raíz para guiar a herramientas compatibles.
- Handoff explícito por Issue/PR/archivo cuando cambie de agente.
- Merge y despliegues reservados a personas autorizadas.

## Alternativas
- Compartir prompts manualmente: rápido pero sin trazabilidad.
- Orquestador por APIs: más automatización, pero costos y complejidad innecesarios inicialmente.

## Consecuencias
Ventajas: control, trazabilidad, independencia de cuentas y continuidad entre sesiones.
Costos: cada agente debe leer el repositorio; hay revisiones y gestión humana. Los documentos no garantizan ejecución autónoma.

## Aprobación
Marcar este ADR como **aceptado** tras revisión y merge por una persona responsable.
