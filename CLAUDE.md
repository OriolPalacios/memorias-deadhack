# Claude Code — DeadHack

Este repositorio comparte las mismas reglas con Codex y otros agentes. Lee `AGENTS.md` y, en este orden:

1. `memorias/README.md`
2. `memorias/CONTEXTO.md`
3. `memorias/PROTOCOLO.md`
4. `memorias/ESTADO.md`
5. Tu Issue y los contratos relevantes.

Trabaja únicamente en tu rama, respetando las rutas asignadas. No cambies archivos compartidos para adaptar silenciosamente una interfaz; propone cambios de contrato en un PR. No hagas merge ni actives servicios pagados. Sigue el protocolo de handoff.

El [harness del MVP](harness/README.md) define contratos, roles de modelos y skills portables. Lee también el [spec](docs/SPEC.md) y su estado antes de implementar. Una contribución desde otro entorno debe declarar agente/modelo, Issue, revisión del contrato y evidencias; no presupone acceso a conversaciones de Codex o Antigravity.
